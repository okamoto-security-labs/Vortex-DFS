# Security Policy

Thank you for helping improve the security of Vortex DFS.

Security reports are handled privately until they have been investigated and resolved.

---

## Reporting a Vulnerability

Please do not disclose vulnerabilities publicly.

Instead, report them directly to the maintainers.

Email

gugaokamoto1@gmail.com

Include, when possible:

- affected version
- reproduction steps
- expected behavior
- observed behavior
- impact assessment
- proof of concept (optional)

---

## Disclosure Process

Every report will be:

- acknowledged
- investigated
- reproduced
- fixed when confirmed

After a fix is available, coordinated public disclosure may occur.

---

## Scope

Examples include:

- authorization bypass
- policy bypass
- runtime trust manipulation
- privilege escalation
- execution without authorization
- denial of service
- unsafe memory behavior
